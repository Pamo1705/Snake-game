## 🎮 The game

Fast to learn, tricky to master. Guide your snake around the board, collect apples to earn points, and avoid crashing into the walls or yourself.

- ✨ **Neon arcade look** with a dark, glowing game board
- 🎨 **Two colour themes** to choose from
- 🏆 **High-score tracking** saved in your browser
- 📱 **Touch-friendly controls** with swipe and on-screen direction buttons
- ⌨️ **Keyboard support** for desktop play
- ⏸️ **Pause, restart, and fullscreen** whenever you need them
- ⚡ **Consistent game speed** — the challenge comes from your skills

## 🕹️ Controls

| Action | How to play |
| --- | --- |
| Move | Arrow keys or **W A S D** |
| Mobile movement | Swipe on the board or use the direction pad |
| Pause / resume | **Space** or the Pause button |
| Start / restart | Use the on-screen buttons |
| Fullscreen | Select **Fullscreen** |

## 🍎 How to play

1. Press **Play** to start a round.
2. Choose your favourite snake-and-apple colour theme.
3. Collect apples to earn **10 points** each.
4. Avoid the walls and your own tail.
5. Beat your best score. Then go again!

## 🚀 Play online

**[Play Neon Snake now](https://pamo1705.github.io/Snake-game/)** — no installation needed.

Want to run it locally? Download or clone this repository, then open `index.html` in a modern web browser.
