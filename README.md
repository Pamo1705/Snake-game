# Snake Game

A dark-mode neon Snake game.

## Play

[**▶ Play Snake**](https://fefe1705.github.io/Snake-game/)  
[**View source on GitHub**](https://github.com/Fefe1705/Snake-game)

If the game page shows a 404, enable GitHub Pages in **Settings → Pages**. Set **Source** to **Deploy from a branch**, choose **main** and **/(root)**, then save. GitHub Pages may take a few minutes to publish the site.

## Controls

- Arrow keys or WASD: move
- Space: pause or resume
- Restart: start a new game
